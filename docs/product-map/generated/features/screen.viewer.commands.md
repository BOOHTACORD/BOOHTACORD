# Просмотр демонстрации

ID: `screen.viewer.commands`

Описание: A selected stream stays mounted across text, DM and workspace navigation within the active voice lease and opens in the mini-player automatically; returning to voice hands the renderer back, fullscreen exit preserves viewing, and stop unsubscribes remote video/audio without leaving voice.
