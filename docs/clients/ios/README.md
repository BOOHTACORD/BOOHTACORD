# iOS-клиент BOOHTACORD

**Исторический статус на 2026-09-28 (не текущая сборка):** iOS runner находится в [`clients/flutter/ios/`](../../../clients/flutter/ios) и использует общий Flutter-код [`clients/flutter/lib/`](../../../clients/flutter/lib). Версия локальной сборки — `1.0.0+1`, bundle ID — `ru.boohtacord.app`, минимальная версия iOS — 15.0. После синхронизации с GitVerse `master` (`426ec29`) подписанная release-сборка установлена по проводу на iPhone 17 с iOS 27.0. Иконка из общего [`app_icon.jpg`](../../../clients/flutter/assets/branding/app_icon.jpg) отображается на домашнем экране, приложение запускается. Это не подтверждает голос, демонстрацию экрана и полную функциональную приёмку. [Запись проверки](../../../evidence/ios/ios-wired-release-install-2026-09-28-001.json).

Позднее исправлены высота полей входа и поведение при временном сбое проверки сессии. Исправленная сборка [проверена тестами, установлена поверх приложения и запущена](../../../evidence/ios/ios-session-retry-input-height-2026-09-28-001.json). Сохранность конкретной пользовательской сессии без просмотра приватных данных не подтверждалась.

В компактном интерфейсе iOS и Android добавлены [девять жестов](GESTURES.md) для боковых панелей, ответа на сообщения, обновления истории, голосовой панели и полноэкранного просмотра. [Release-сборка с жестами](../../../evidence/ios/ios-swipe-gestures-2026-09-28-001.json) установлена поверх текущего приложения и запущена на iPhone; физическая проверка самих жестов остаётся открытой.

Предыдущая [сборка мобильной шторки и плавных переходов](../../../evidence/ios/ios-mobile-start-drawer-smooth-transitions-2026-09-28.json) открывала навигацию при входе и содержала промежуточный выбор «Чаты / Голос». В ней также добавлен прямой вход в голосовую комнату с однократным переносом прежнего подключения при ответе `ACTIVE_VOICE_LEASE`. При той проверке запуск был заблокирован экраном iPhone; ручная проверка интерфейса и состояния входа остаётся открытой.

Следующая [сборка с исправлением свайпа в голосовом канале](../../../evidence/ios/ios-voice-drawer-drag-scroll-2026-09-28-001.json) прошла 218 Flutter-тестов, установлена поверх приложения и запущена на iPhone. Горизонтальный жест больше не прокручивает голосовой экран при небольшом отклонении пальца по вертикали; ручная проверка на устройстве остаётся открытой.

В текущей [сборке с единым списком каналов](../../../evidence/ios/ios-unified-general-channels-2026-09-28-001.json) убраны переключатели «Чаты / Голос»: текстовые и голосовые комнаты видны вместе в категории General и других категориях сервера. Сборка прошла 218 Flutter-тестов, установлена поверх приложения и запущена на iPhone. Ручная проверка вида шторки на устройстве остаётся открытой.

Разработка и установка выполнены по запросу владельца проекта. [ADR-006](../../adr/ADR-006-android-client.md) описывает более ранний Android scope; решение о публичном iOS-релизе и критериях поддержки устройств принимается отдельно после [приёмки](ACCEPTANCE.md).

## Разработка и проверки

1. [DEVELOPMENT.md](DEVELOPMENT.md) — инструменты, сборка, подпись и платформенные решения.
2. [ACCEPTANCE.md](ACCEPTANCE.md) — проверенные и открытые сценарии до выпуска.
3. [GESTURES.md](GESTURES.md) — свайпы для навигации, переписки, голосовой панели и трансляции.

Камера, запись, group DM, глобальные гильдии и собственный SFU не входят в клиент. Текущий UI → `features/screen/setup/open_dialog/mobile_notice.dart` →
`features/screen/capture/driver.dart` использует два явных пути:
без «Передавать звук экрана» — app-only video; с этим переключателем —
системная трансляция ReplayKit через ScreenShareExtension. Подсказка перед
запуском объясняет изменение области захвата. Системное разрешение обязательно.
`SampleHandler.swift` передаёт `.video`/`.audioApp`, исключает `.audioMic`.
App Groups, embed extension и отдельный provisioning необходимы для подписанного
broadcast-пути. Это наличие кода, а не сертификат физической приёмки.

Состояния различаются: **coded** — путь есть в source; **build-available** —
конкретный runner скомпилирован; **shipped** — подписанный IPA/source SHA
подтверждён release receipt; **runtime-verified** — конкретный сценарий пройден
на указанной ОС/устройстве. iOS Simulator пригоден для UI/API smoke, но не
подтверждает системную трансляцию, audio/background, OS stop или поворот при
захвате. Эти физические сценарии остаются в #62/#132/#303. Текущая матрица и
сборки: [#518 evidence](../../../evidence/qa/issue518-client-parity.md).
Минимум runner — iOS 15.0; доступность ReplayKit зависит также от permissions,
подписи extension и разрешений источника. Старое свидетельство сборки выше не
подтверждает новую опубликованную версию.
