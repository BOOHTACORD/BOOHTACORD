# Synthetic reference corpus

`synthetic-v1.json` identifies the three 48 kHz signals generated by
`synthetic_pcm_fixtures.mjs`. SHA-256 covers raw mono IEEE-754 float32
little-endian samples. Source amplitudes are fixed; no RMS normalization is
applied. These CC0 signals are not speech and cannot establish intelligibility
or perceived quality.

Run `node --test tools/audio/corpus/test_manifest.mjs` from the repository
root. The audio quality harness rejects a corpus that differs from the frozen
reference. When deliberately introducing a different corpus, version it and
retain the old reference for comparisons; do not regenerate a reference merely
to make a failing check pass. `node tools/audio/corpus/snapshot.mjs` prints a
candidate reference for review.

Consented speech and physical-device measurements require separate provenance
and permission; keep private recordings out of the repository and logs.
