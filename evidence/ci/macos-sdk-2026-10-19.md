# #400 — hosted macOS and isolated patched SDK implementation

Date: 2026-10-19. Baseline: 59c15c65c6751173fc5e668be383e88a62276a58.
Parent: #382. Implementation-first scope requested by the owner: focused local
checks only, without expensive native app/SDK runs after every leaf.

## Implementation

Removed the unprovisioned self-hosted macOS CI dependency. Fast metadata/package
fixtures run in mandatory PR contracts; full universal app build is explicit on
a disposable hosted Mac. Exact reviewed Apple toolchain selection now guards
native CI and stable app release; stable tag/version/master ancestry, signing
queue, ad-hoc signature, checksums and immutable native release behavior remain.

SDK compilation stays dispatch-only. Separate plan/build/assemble/publish jobs
bind fresh owned workspaces, builder source/run/attempt, upstream/depot commits,
recipe/host-policy/patch hashes, actual thin/universal Mach-O architectures,
executed native regressions on both hardware architectures, test-report/archive
hashes and cleanup. Existing versions are rejected before a requested publication
spends the 180min build budget. A complete verified universal candidate is
published only on explicit protected master dispatch, through a draft with
verified asset digests and tag-source readback. No SDK consumer URL/checksum is
changed automatically; native SwiftPM inputs join the reviewed inventory.
