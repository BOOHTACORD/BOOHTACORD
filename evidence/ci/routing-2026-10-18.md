# CICD-02 / #384: unified routing

Implementation: one versioned dependency map serves PR gates and server build.
Unknown/missing diffs run all gates and select both release impacts. Ordinary
 docs/evidence/backlog and native-only changes do not run the server receipt gates
or signer. Shared network evidence, RNNoise, release/archive and policy code retain
conservative coverage. PR contracts remain unconditional; every signed server
build still depends on all three exact-source release receipts.
