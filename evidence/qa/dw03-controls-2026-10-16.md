## Control contract

Extend existing `gc-button` and semantic tokens; do not create global button
paint rules. Primary uses accent/on-accent, secondary raised surface/border,
ghost transparent/secondary text, destructive danger-solid/on-danger. Disabled
and busy retain real native disabled semantics; existing busy labels remain.
Icon-only variants require an accessible name and a title. Focus uses the
existing focus token; compact desktop minimum is 36px, narrow/coarse pointer
minimum 44px, with rem-based growth and wrapping. `gc-field` applies only to
explicit text/search/select fields. Native select popups, arrow keys, checkboxes,
ranges and audio switches keep their native/specialized behavior.

Removed conflicting duplicate paint rules instead of stacking another blanket
override. Existing handlers and warnings/confirmation text are preserved.
