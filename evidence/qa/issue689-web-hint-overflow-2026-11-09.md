# Issue 689: Web coalesced-hint overflow

- Before the change, two focused tests demonstrated that 257 hints could accumulate in the coalescing buffer without invoking recovery, including while an earlier batch was blocked. The existing 256-item limit applied only to the downstream delivery queue.
- The coalescer now bounds the combined pending, queued and in-flight hints at 256 and invokes the delivery failure path on the next hint. That path clears the cursor and requests reconnect/recovery. A generation check prevents a late batch completion after failure from changing the new generation's accounting or acknowledging the old event. The existing immediate lease-revoke path is preserved.
- PASS: all 53 tests under `clients/web/src/realtime`, including four focused overflow tests covering the exact limit, pre-timer overflow, in-flight backlog with an immediate revoke, and late completion after recovery. The first build found a TypeScript return-type mismatch after adding the internal abort operation; it was fixed. The next build passed type checking but failed because the required `VITE_PUBLIC_ORIGIN` was missing; with the synthetic origin `https://voice.example.test`, the complete production-mode Web build passed. Vite reported existing large-chunk and dynamic-import warnings.
- This is focused client-level evidence. It does not yet prove real server socket backpressure, revoke during every overflow race, a complete client resync, native clients, final feature acceptance or release readiness. The scenario is registered in `tools/qa/local_features/features.json`.
