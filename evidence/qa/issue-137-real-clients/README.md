# Issue 137: real-client retry acceptance

Observed 2026-11-07 on disposable loopback-only Go API/PostgreSQL/LiveKit stack built from master `c2bb5867a87d383921ce5d7159b23532dd1dd484`. The two clients used different synthetic fixture accounts. There were no production accounts or production requests. Both tests first made eight actual incorrect login requests, then submitted valid credentials through the client form while the account window was active. The response was a real 429 with a positive Retry-After. Both tests observed request counts, waited past expiry without further form action, then submitted once more.
