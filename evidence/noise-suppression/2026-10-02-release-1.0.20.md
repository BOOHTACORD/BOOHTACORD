## Server and open acceptance

The server source scope did not change in this native rebuild. Production
remains independently verified at `52c6320`: API and Web revision labels, image
config digests, public health, pinned audio assets, MIME, license, SBOM and
404 handling all passed. The [initial release record](2026-10-02-release.md)
binds the actual server build and successful deployment.

The [automated gate record](2026-10-02-automated-gates.md) records the implemented
graph, processed synthetic PCM through a real browser and LiveKit SFU, mute and
resource ownership checks, native core tests and universal macOS compilation.
Those results do not close physical microphone, listening, AEC/double-talk,
PTT/deafen, USB/Bluetooth, background audio, screen/system-audio coexistence,
minimum-device timing, stability or load gates. Apple explicitly reports the
RNNoise mode unsupported because the current SDK couples hardware AEC and NS;
the standard-engine fallback preserves AEC. The first release remains opt-in
with standard noise suppression as the default.
