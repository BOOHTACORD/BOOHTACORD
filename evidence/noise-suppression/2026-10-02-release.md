overlays only in the build directory. Stock and transformed host builds
produced byte-identical deterministic PCM over 100 frames and reset/replay:
SHA-256 `72ef6df5c6e47d5a2526b8fd4432dc329f97f1b8f70e1d95583e9d5791f1a436`.

## Remaining acceptance

The [automated gate record](2026-10-02-automated-gates.md) records 759 Web tests,
404 Flutter app tests, 433 vendored LiveKit tests (one additional skip), 18
vendored WebRTC tests, five real Chromium/SFU tests and a universal macOS release
build. Tool checks subsequently passed 87 Python tests after build regressions
were added, plus two new fresh-checkout regressions. Authored synthetic PCM is
not evidence of real speech quality.

The plan's physical AEC/double-talk, live listening, PTT/deafen, USB/Bluetooth,
background routing, screen/system-audio coexistence, minimum-device callback
latency, 60-minute stability and multi-sender load gates remain NOT_RUN.
macOS/iOS explicitly fall back to the standard engine because the current
Apple SDK couples hardware AEC and NS; RNNoise is reported unsupported there.
No acoustic or capacity gate is closed by successful compilation or deployment.
